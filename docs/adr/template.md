# ADR 模板

- Status: Proposed
- Date: YYYY-MM-DD
- Deciders: 姓名 / 角色

## Context

要解决什么问题？有哪些约束（平台、零依赖、正在使用中、历史决策）？
不写实现细节，只写导致决策的事实与冲突。

## Decision

选择了什么？给出可执行的边界（路径、命令、格式、事件名）。
如果有多项，用表格或编号列出。

## Consequences

- 正面结果。
- 代价、限制、运维要求。
- 对文档、测试、安装器、运行时副本的影响。

## Alternatives considered

- 方案 A：为什么否决。
- 方案 B：为什么否决。

## References

- 相关文件、测试、官方文档链接。
