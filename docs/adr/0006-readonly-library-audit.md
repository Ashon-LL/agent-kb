# ADR-0006: 库审计只读

- Status: Accepted
- Date: 2026-11-10
- Deciders: ACHEN

## Context

库已有 298 条，缺少系统化的重复、零入链、过期检查。
自动合并或删除条目风险高：两条措辞相近的条目可能是不同事实，
误删会直接损失经验资产。

## Decision

`kb_audit.py` 只产出报告，不修改条目：

- **同族重复**：title + description + 正文前 800 字的 token 余弦，阈值默认 0.55。
- **零入链**：统计全库 `[[链接]]`，没有其他条目指向的列为孤儿。
- **入链建议**：为孤儿找相似条目，阈值 0.20，只建议不写入。
- **过期待复核**：`verified/date` 超过 180 天，含状态词的单独标记。
- **topic 分布**：按条目 topic 统计。

## Consequences

- 审计约 1 秒完成，可定期跑，不影响 hook。
- 重复/合并/删除仍需人工确认；报告是线索，不是结论。
- 同族阈值偏严时可能 0 对，说明当前库没有高相似重复，不代表审计失败。
- 入链建议只补真实关系，禁止为凑指标硬拉。

## Alternatives considered

- **自动合并/删除**：误删不可逆，已否决。
- **只靠人工体检**：容易漏、不可复现，已否决。
- **引入图数据库**：违背零依赖，已否决。
