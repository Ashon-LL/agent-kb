## 旁白完整文案（朗读参考）

> 你有没有过这种感觉——同一个坑，AI 帮你踩了三次？
>
> 第一次它说"好问题我会注意的"，第二次"抱歉上次没做好这次一定行"，第三次……你已经想打它了。
>
> 今天给大家介绍一个我自己开发的小工具——agent-kb。一个让你的 AI Agent **终身不重复踩坑**的全局经验库系统。
>
> 它分四层。最下面是纯 Markdown 库，中间是 Skill 统一规程，上面是命令入口，最顶层是 Hook——自动在开工前提醒、收工时拦截沉淀。
>
> 看，这是 TraeWork 启动瞬间，Hook 自动注入了"开工先扫经验库"的提醒。现在我输入"记住这个坑"——它立刻拦截，告诉我按规范写进经验库。
>
> 所有经验都是纯 Markdown，按工具链、工作流、教训三类分目录。每条都有 frontmatter，检索时直接 grep。人类也能读。
>
> 安装就一行命令。Windows 上跑 install.ps1，选好平台——Trae、ZCode、Codex CLI 都行，自动搞定 Skill、Hook、空库三件套。
>
> 用的时候更简单。检索 `/kb 关键词` 直接返回命中条目全文。沉淀 `/kb add 经验` 自动判类、查重、写文件、更新索引。
>
> 最重要的一点——**这个东西永远不会卡死你的 Agent**。哪怕 hook 脚本全坏了，它静默返回零，主会话完全不受影响。
>
> 仓库地址在屏幕上。Star 一下，fork 回去改改，或者直接提 issue。
>
> 让 Agent 踩一次、沉淀一次、终身受益。就这么简单。下期见。

## 画面要点

1. **架构动态图**：四层从下往上依次浮现，每层配一个"咔哒"音。可以用 draw.io 画一张静态图，录屏时配合屏幕录制工具的标注功能动态高亮
2. **Hook 效果演示**：关键——必须是真实屏幕录制，不能用动画。TraeWork 启动瞬间的 hook 注入内容要能看到，然后"记住这个坑"触发沉淀规程
3. **库展示**：展开 `~/.agents/kb/` 目录，点击 INDEX.md → 点击某个具体条目 → 展示 frontmatter 格式
4. **零阻塞验证**：删除 `trae_zcode_adapter.py` 后重开会话，展示 Agent 正常启动、正常对话
5. **结尾仓库**：`git clone https://github.com/<your-org>/agent-kb.git` 命令在终端输入 + Star 按钮高亮
