description: 扫描各项目 memory 与当前会话空间，产出经验晋升候选清单，用户确认后写入全局 kb。
argument-hint: "[可选：指定扫描的项目路径]"
---

执行一次全局经验收割。两类来源都要扫：

1. **项目记忆库**：根据当前平台定位各项目的 memory 目录（Trae: `~/.trae-cn/memory/projects/*/`；ZCode: `~/.zcode/cli/memories/projects/*/memory/`；其他平台扫描当前工作区的 `.memory/` 或 `memory/`）。
2. **当前会话的项目空间**：以本会话工作目录为根，扫描经验型文档——文件名含「指南、手册、上手、给其他项目、交接、总结、复盘、教训」的 md，以及 `docs/`、`notes/`、`交付/`、`.analysis/` 等文档目录。**若当前工作目录是空沙箱，停下问用户要路径或从 $ARGUMENTS 指定。**

步骤：

1. 逐个读各项目 memory 索引，按需读条目全文。
2. 按 kb 技能收录标准筛选：**跨项目可复用**的经验/教训/方法才入选；项目专属状态剔除。已在 INDEX.md 存在的跳过。
3. 输出晋升候选清单给用户过目，格式：`来源 | 拟入目录 | 标题 | 一句话理由`。到此为止，**不要未经确认直接写入**。
4. 用户确认后逐条按 kb 写入规程落盘、更新 INDEX.md。
5. 汇报最终写入的条目路径列表。
