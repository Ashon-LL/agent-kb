**经验**：下次数模论文可直接套用的视觉基线（用户参照近两年展示论文提出，已验收）：

1. **数据图要"高级图型"，只统一字体不够**。目标图型：云图叠等值线 + 色标带单位、判据曲线加 **inset 放大穿越点**、对照图加 **Δ 差值面板**、收敛图改**分组柱状 + 数值标签**、因素分离改**瀑布图**、量值区间加**阴影带**、灵敏度 **Tornado + 参考竖线**、多面板加 **(a)(b) 编号**。
2. **rcParams 基线固化在画图脚本顶部**：`font.size=10`、`axes.labelsize=10.5`、`xtick/ytick.labelsize=9.5`、`legend.fontsize=9`（带框）、`lines.linewidth=1.8`、`axes.grid=True` 点状网格 alpha .3、刻度朝内；**不得再写小于 9pt 的显式字号**（原图大量 7–8pt，缩到 16cm 栏宽后不可读）。
3. **示意图**：流程图/框图**严格白底黑线**（不用彩色填充，最多浅灰 `#f5f5f5`，靠线型与灰度分层）；几何/物理示意图可用低饱和浅色，但仍须白底、细黑线、带箭头细黑坐标轴。线宽 1.5–2、直角折线、实心箭头；按约 16cm 栏宽设计，标注 12–13pt、标题 14–15pt。**示意图优先画模型结构**（坐标系与几何近似、控制体/网格离散、坐标变换、时序与判据），而不是堆更多数据图。
4. **摘要**：首段 = 背景一句 + **方法/创新清单（方法名带缩写）**；随后**每问一段**，按 **方法名 → 求解手段 → 具体数值结论 → 验证（误差/对照）** 排；验证信息散在对应问题段里，**不要集中成末段的纯指标罗列**。**挑重点加粗**：方法名、口径裁定的结论词、每问 headline 数值、验证结论（加粗不改变长度，故仍可守住 1 页）。
5. **必须有「模型汇总」小节**：把各问的 PDE + 初边值 + 物性 + 判据集中成"**求解目标 + `cases` 方程组 + 定解条件**"，点明各问差异仅在**物性/计算域/终止时刻**三项。形态取"**四问合一**"（共用同一套控制方程时拆块会重复 90%），末尾补约 4 行"各问设置清单"，**用列表不用新表格**（插表会触发全篇表号重编）。
6. **模型缺点**：只留真正的局限，每条附量化影响；剔除非缺点（"数据规模较大"这类自曝式）与已在正文讲透的重复项；精简只允许"移动位置、改语气"，删掉的事实必须能在正文别处举出。

**How to apply**：写数模论文时把 1–3 条落到 `code/make_figures.py` 的 rcParams 与图型选择，4–6 条落到摘要与 §"模型汇总"；出图后逐张目视（见 [[figure-placement-and-legend-occlusion]]）。
