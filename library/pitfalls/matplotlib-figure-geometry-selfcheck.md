**经验**：出图步骤不能只"脚本跑完就算"。**图例压柱、注释压柱、文字出画布**这类缺陷在 PDF 里必须逐张放大才看得全，人工复检成本极高；必须在 `savefig` 前用 bbox 几何量自检，且**只有几何量可靠**（对 PDF 做像素启发式误报率高）。

**实测的三层根因（matplotlib 通用，非本项目特有）**：
1. **触发条件错位**：避让逻辑写在 `if len(user_texts) < 2: continue` / `if not has_overlap: continue` 之后 ⇒ 没有任何标注的柱状图（最常见形态）图例永不避让。
2. **看不见柱子**：只统计 `ax.get_lines()` / `ax.collections`、漏 `ax.patches` ⇒ 柱状图上"数据点集"为空，直接盲返默认角位（实测 18 根柱子被当成 0 个数据）。
3. **`Annotation.get_window_extent()` 返回「文字 ∪ 箭头」**：箭头锚点钉在数据点上，移动文字时并集几乎不变（实测位移 30 数据单位只让 bbox 变 3px）⇒ 任何基于 bbox 的避让都判「挪了没用」。**必须取 `Text.get_window_extent()` 基类实现**。

**其余实现要点（都是踩过才知道）**：
- 图例落位内边距不能用固定 6px 估：matplotlib 实际按 `borderaxespad × fontsize × dpi/72` 内缩（默认 0.5 → dpi300 约 21px）；估小了会"判定不重叠、实际压柱顶"。
- 抬 `ylim` 造留白是唯一安全的"腾地方"手段（塞到 axes 外会被 `bbox_inches='tight'`/standard bbox 裁掉）；**必须设总增幅上限**（如 +40%），否则图例与文字两处兜底会叠乘（实测 0–105 被抬到 0–350，柱子缩成一条）。
- 柱内数值标签要豁免，但**豁免判据必须含"水平居中"**：只判"落在柱内"会把参考线标签也放过，然后被挪进柱身。
- 布局守卫（tight_layout/subplot 兜底/刻度避让）会**重排**，把刚让开的位置推回去 ⇒ 保存前要按最终布局**再避让一次**，然后才自检。
- 门禁脚本必须在**临时副本**里重跑生成脚本（不污染工作区），并**强制使用随附的工具库**——用工作区里那份旧库等于让被测物自己关掉门禁（实测旧工作区 rc=0 违规=0，而图例仍压柱子）。
- 作者显式 `loc=` 不能无条件尊重：压住数据时也要挪，但优先同侧并留 `[FIG-QA] NOTE`（静默篡改会让代码与画面不一致，极难排查）。

**验收口径**：门禁退出码 = 违规数；正例（能自动修）必须 0 违规，负例（如 28 条图例放不下）必须报 `legend overlaps`。只验"能过"不验"能拦"= 空转门禁。
