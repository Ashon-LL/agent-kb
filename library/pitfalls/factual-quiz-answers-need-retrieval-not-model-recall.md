**经验**：自动化答题、题库批改、竞赛题、认证考试这类"答案客观存在"的任务，
作答前应先用检索工具（tavily / bocha 等搜索 MCP）核对题干，再结合排除法决策；
模型凭训练记忆给出的判断只作初筛，不能单独作为提交依据。

**Why**：《中学生心理辅导》13 套章节测验（共 125 题）实测：只凭模型判断时，
多选题在"教材条目数"类问题上反复出错（1.4 的 Q3/Q4 该选 AB 却全选/错选，直接丢 20 分），
判断题也会按常识而非教材措辞判错（Q9）。而改为对照教材表述的几套（2.5、9.5、12.2）拿到满分 100。
单题检索耗时以秒计，错一题的代价是整题 0 分且通常不可重做。

**How to apply**：
- 检索词用「题干核心短语 + 答案」或「题干 + 教材名」，别把整段长题干塞进去（命中率低）。
- 多选题重点核对"教材列了几条"——搜到的条目数直接决定选几项；全选只在确认是穷举事实型时使用。
- 判断题核对原句措辞：人名/年代/顺序类（如"疾风怒涛"是霍尔不是弗洛伊德、埃里克森 4+1+3 分段）最易错。
- 两个来源冲突时，优先教材/课程原文，其次题库站点，最后才是通用问答。
- 提交后仍按得分反推校准：少选得半分、错选 0 分，可用于修正同章后续题。
