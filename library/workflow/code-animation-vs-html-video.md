**经验**：判断一个视频是「代码动画」还是「HTML 风格」，不看它用 Remotion 还是 After Effects，看**场景语法**。七条判据：

1. **连续世界 vs 卡片容器**：数据、标题、图例、注释在同一个有透视/遮挡/景深的空间里；不是「左边说明 + 右边图卡 + 底部 KPI 卡」的网页版式。
2. **摄影机 vs 页面滚动**：每段有 dolly/pan/zoom/焦点变化；转场是镜头穿过、物体变形或空间重构，不是硬切/黑场/淡入。
3. **物体持续 vs 重新布局**：上一镜的柱子/数字/曲线留在下一镜，被移动、拆解、变形；不是每段重新挂一套 DOM。
4. **连续微动 vs 静止帧**：任意 2 秒内都有运动（相机漂移、光带、粒子、数据呼吸）；`freezedetect` 不应连续命中。
5. **光/材质/合成 vs 平面色块**：真实 bloom/DOF/反射/雾/颗粒；数据条有厚度、高光、落地影，而不是纯色矩形。
6. **字是几何 vs 文本框**：标题/数字/标签跟着透视和物体走，可被遮罩、逐字、尺度变化；不是左上角一段固定说明文。
7. **声音是运动的一部分 vs 背景音乐**：whoosh/impact/tick 与位移、落点、转场同帧；有侧链/混响/LRA 设计。

**参考对照**（2026-11-06 实看抽帧）：

- **3Blue1Brown《线性代数的本质》**（Manim，代码动画）：一整块网格世界；向量/矩阵/标签跨镜持续存在；2D 网格连续变形成 3D；镜头推拉与空间变换代替切镜；蓝/橙/白三色语义稳定；英文公式与中文字幕是画面的一部分；几乎无静止帧。
- **疫情数据可视化**（B 站 BV1F54y1v79s）：白底、条形竞赛 + 国旗 + 大日期 HUD；平视、无景深、无光照；运动只有条形增长；典型「会动的仪表盘」。
- **EP02 自审**：S1 天平钩子接近前者（3D、相机、bloom、粒子字幕）；S2–S5 数据段接近后者（左侧标题/正文 + 右侧图表卡 + KPI 卡，5 秒静止）。技术是 Remotion，但数据段用的是 HTML 版式语法。

**Why**：用网页版式做视频，信息再准也会被感知为「网页录屏/会动的 PPT」：没有镜头、没有空间、没有质感；观众记不住，平台完播也吃亏。代码动画的核心不是「代码」，而是每一帧都经过场景、镜头、光、合成和声音设计。技术栈只决定实现方式，不决定风格。

**How to apply**：下一个数据段开工前先画「世界图」——相机路径、空间中的物体、光源、文字层级、声音落点——再写组件。验收时对每帧问三句：这帧像电影截帧还是网页截图？连续 2 秒有没有运动？转场有没有改变空间？具体改造优先级：

1. 去掉卡片边框/底色/KPI 卡，把 KPI 变成世界里的发光数字或刻度。
2. 每段一个连续镜头（dolly/pan/zoom），柱子/曲线做成有厚度的 3D 物体。
3. 用「柱子→曲线→数字」的形变承接段落，而不是切镜。
4. 给图表加落地影、扫描光、景深、粒子；标签跟随物体。
5. 任何 2 秒内至少一个连续运动；用相机漂移/呼吸避免 freeze。
6. 字幕可粒子化，但位置可贴物体/随透视，不必永远底部居中。
7. 声音与运动同帧：转场 whoosh、落点 tick、定格 impact；母带 LRA 6–9。

技术映射：Remotion 的 `useCurrentFrame` + spring/插值驱动 three/Canvas/SVG；不要靠 DOM 截图或 CSS 状态动画。工程坑见 [[remotion-project-gotchas]]。

**2026-11-06 EP03 v2 增补：把「像不像电影」变成可测数字**

EP03 v1 被用户判「完全不对」后复盘的硬指标（同一套脚本可复用到下一条片）：

| 指标 | v1（被否） | v2（通过） | 测法 |
|---|---|---|---|
| 全片平均亮度 | 13.2/255 | 51.4/255 | OpenCV 逐帧 `frame.mean()` |
| 亮度 p90 | 20.5 | 62.6 | 同上，取 90 分位 |
| 帧间差均值 | 1.30/255 | 2.14 | 相邻帧灰度差均值（320×180） |
| 任意 2s 最小变化 | ≈2.5 | **9.18/255** | 每隔 2s 取帧对相减 |
| 主数字字号 | 26–76px | **132–150px** | 设计稿 |
| 主体占画面 | <25% | **>50%** | 抽帧目视 |

**Why**：v1 的失败不是「暗」，是「黑场 + 主体太小 + 静止」三件事叠加；只看静帧看不出来，因为每张静帧都有细节，缩到观看尺度就只剩黑底上一点光。量化后问题一次暴露。

**How to apply**：
1. 开渲前先定「夜戏/日戏」的亮度目标（夜戏均值 ≥45，日戏 ≥80）；渲完立刻跑一遍均值/分位/2s 差，不达标就调光，不看感觉。
2. 相机关键帧按「距离主体 8–20 米、高度 5–10 米」写；不要用 40 米外的全景当主镜头——那等于把小模型缩到画面角上。
3. 数据字号：主数字 ≥120px、标签 ≥26px；不要用 26–40px 当数据正文。
4. 每段至少一个「镜头穿过/贴脸掠过」的近距离运动，2s 差才拉得起来。
5. 静帧自审只能证明「这一帧能看」，不能证明「这一段成立」；必须 1fps 接触表 + 2s 差指标一起看。
